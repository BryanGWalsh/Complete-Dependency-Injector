# Installation

## Dart

Add the core package:

```sh
dart pub add complete_dependency_injector
```

## Flutter

Add both packages. The Flutter package builds on the core one.

```sh
flutter pub add complete_dependency_injector complete_dependency_injector_flutter
```

## Import

```dart
import 'package:complete_dependency_injector/complete_dependency_injector.dart';

// Flutter apps also import:
import 'package:complete_dependency_injector_flutter/complete_dependency_injector_flutter.dart';
```

## Requirements

- Dart SDK 3.8.1 or later
- Flutter 3.0 or later, for the Flutter package
